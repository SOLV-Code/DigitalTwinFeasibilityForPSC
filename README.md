# Digital Twin Feasibility For PSC
Development repository for feasibility study of Digital Twins in a Pacific Salmon Commission context

## Structure

This repository is designed for streamlined collaboration across a diverse and dispersed group of experts ranging from digital twin enthusiasts to the operational modellers who build and maintain decision-support tools for the [Pacific Salmon Commission (PSC)](https://www.psc.org/).

Evolving building blocks are self-contained within topic folders that each have a main *readme* file as a starting point and then take shape as needed. Contributing experts can edit the building blocks directly in the browser by clicking on the pencil icon (top right), adding/revising text as needed, and then clicking *Commit Changes" (top right).

The main deliverable for this process is a feasibility study establishing clear definitions, summarizing digital twin concepts, and describing in detail a few candidate case studies of digital twins that are both feasible and relevant in the PSC decision context. The feasibility study will be written and published as an open-source markdown report that can easily be expanded and updated even after the formal project has wrapped up in March 2028.
