# DigitalTwinFeasibilityForPSC
Development repository for feasibility study of Digital Twins in a Pacific Salmon Commission context

## Structure

This repository is designed for streamlined collaboration across a diverse and dispersed group of experts ranging from digital twin enthusiasts to operational modellers building and maintaining decision-support tools for the [Pacific Salmon Commission (PSC)](https://www.psc.org/).

Evolving building blocks are self-contained within topic folders that each have a main *readme* file as a starting point and then take shape as needed. 

The main deliverable for this process is a feasibility study establishing clear definitions, summarizing digital twin concepts, and describing in detail a few candidate case studies of digital twins that are both feasible and relevant in the PSC decision context. The feasibility study will be written and published as an open-source markdown report that can easily expanded and updated after the formal project has wrapped up in March 2028.

## Timeline

This project will progress through four distinct phases. The preparation phase has started as part of the proposal development. The general scoping phase will then start off the more intensive expert process with a focus on sorting out definitions and identifying best practices, planned to coincide with the PSC’s pre-season planning activities. The bulk of the project timeline is dedicated to the PSC-focused phase, which will coordinate qualitative evaluations of specific digital twin ideas while existing decision-support tools and data flows are in active use during the season. Finally, the synthesis phase will consolidate the discussions and feedback into clear, practical recommendations and identify a shortlist of 2-3 feasible and potentially useful digital twin candidates with detailed technical specifications.
